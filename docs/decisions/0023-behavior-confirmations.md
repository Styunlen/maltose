# ADR-0023: 用户确认保持现状的三项行为决策

## 状态

已接受

## 日期

2026-08-16

## 背景

代码审查（2026-08-15）标记了三项"行为变更需确认"项。经与用户确认，**三项均保持现状**。本文档记录决策，避免未来被误判为 bug 或无意修改。

## 决策

### 1. 失效友链始终显示访问按钮

- 友链检查（`getFriends`）将链接分为 `active` / `unknown` / `dead` 三态。
- `dead`（暂时失联）与 `unknown`（网络波动待确认）分组**始终展示访问按钮**，由用户自行判断是否点击。
- 不添加失效标记、不隐藏/禁用访问按钮。
- 理由：失效可能是临时网络问题，直接隐藏会阻碍用户访问尚可用的站点。

### 2. ExternalLinkGuard 外部链接确认后新标签页打开

- 外部链接点击 → 拦截 → 确认对话框 → 确认后 `window.open(url, "_blank", "noopener,noreferrer")` 新标签页打开（见 ADR-0022）。
- 不改为当前标签页跳转。
- 理由：不离开当前博客页面，减少用户上下文丢失。

### 3. 浏览数 SSR 时点值，无客户端更新

- 浏览数由 SSR 渲染时点值（每次页面请求实时查询 WP，见 ADR-0003/0015）。
- 页面加载后**不**自动刷新浏览数（ViewCountsProvider 已删除）。
- 不恢复客户端批量刷新。
- 理由：SSR 实时值已满足 ADR-0003"刷新即最新"目标，增加客户端刷新会多一次请求且收益有限。

## 影响

无代码改动。三项均为既有行为的正式确认，记录在案以防回归。
